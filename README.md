# NHL Player Stats Tracker

A Python command-line tool that looks up any active NHL player
by name and prints their current-season stats.

## How to run
1. pip install requests
2. python HockeyStatsTracker.py
3. Type a player name (or 'quit' to quit)

## How it works
Uses the NHL's public API: search by name to get a player ID,
then fetch that player's stats.
